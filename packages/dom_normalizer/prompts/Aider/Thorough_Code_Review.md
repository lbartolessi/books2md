### 🔍 Review exhaustivo
> Realiza un code review exhaustivo del archivo.  
> Evalúa arquitectura, estilo, seguridad, rendimiento, legibilidad y mantenibilidad.  
> No modifiques el código. Solo analiza y clasifica problemas por severidad.

### 🧠 Análisis de arquitectura
> Evalúa la arquitectura del módulo.  
> Identifica acoplamiento innecesario, violaciones de SRP, dependencias implícitas y puntos de fallo.

### 🧪 Test coverage
> Evalúa la cobertura conceptual de tests para este archivo.  
> Indica qué casos borde faltan y qué riesgos introduce la falta de tests.

### 🧹 Refactors sin tocar código
> Sugiere refactors detallados sin aplicar cambios.  
> Explica el impacto de cada refactor en claridad, rendimiento y mantenibilidad.

### 🔐 Seguridad
> Evalúa riesgos de seguridad en este archivo.  
> Señala validaciones faltantes, sanitización, manejo de errores y exposición de datos.
